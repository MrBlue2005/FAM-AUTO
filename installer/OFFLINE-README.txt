RX AI Studio - pachet offline complet (Windows x64)

1. Extrage complet arhiva ZIP intr-un folder local.
2. Ruleaza fisierul RX-AI-Studio-Offline-Setup-<versiune>.exe.
3. Pastreaza folderul implicit din LocalAppData si alege parola administratorului.
4. Porneste RX AI Studio din shortcutul creat pe Desktop.

Pachetul include Node.js, dependentele npm, Chromium Playwright, launcherul si overlay-ul.
Nu necesita Visual Studio, Node.js instalat global sau conexiune la internet in timpul instalarii.

Windows poate afisa SmartScreen deoarece executabilul nu are certificat comercial de semnare.

Dupa instalare, launcherul verifica release-urile oficiale ale repository-ului FAM-AUTO.
Cand apare "Update available", instalarea incepe numai dupa apasarea butonului si confirmare.
Pachetul este verificat SHA-256 inainte ca Studio sa fie oprit si installerul sa porneasca.
